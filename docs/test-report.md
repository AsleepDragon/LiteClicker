## Windows 性能与发布阻断

冷启动、空闲 CPU/内存、50 次/秒资源、7 个频率各 60 秒准确度、至少 30 次停止 ≤150 ms、30 分钟连点和 10 分钟按住，均**未执行**，无实测数值可报告。上面的逻辑测试耗时不代表 Windows 性能。

发布阻断项仍包括：真实两种输入功能、全局停止与释放、WPF/托盘/生命周期、DPI/多屏、单实例跨权限、干净 Windows 11 无运行环境离线运行。需要在 Windows 完成 `windows-validation.md`，保存实际系统构建号、机器参数、CSV、截图与校验值。EXE 未代码签名。

本次发布应作为供验收的预发布，不宣称已经具备经过实机验证的正式可用性。
